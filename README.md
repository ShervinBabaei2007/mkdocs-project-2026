# PNWX UX Redesign - Case Study

A full UX documentation project completed independently as part of BCIT's Communication & UX course (ACIT 2811). The subject is [Pacific Northwest X-Ray Inc.](https://www.pnwx.com/), a medical imaging supplier with significant usability issues across navigation, visual hierarchy, and content organization.

The goal was not to build a prototype - it was to document a complete, defensible UX process from problem diagnosis through tested high-fidelity wireframes.

## Process

**Week 1 - Site Selection**  
Evaluated three candidate sites and selected PNWX based on compounding, well-defined UX problems: visual clutter, inconsistent styling, and an attention-competing link structure.

**Week 2 - Usability Principles & Market Research**  
Applied the seven usability factors to PNWX. Conducted competitor analysis of ProboMedical and GE Healthcare Shop to benchmark structure and hierarchy.

**Week 3 - User Research**  
Built two primary personas (Dr. Sarah Martinez - clinical decision-maker; Mike Chen - non-technical practice manager), user stories, and task scenarios. These became the criteria for all subsequent design decisions.

**Week 4 - Problem Definition & Information Architecture**  
Used the Five Ws to reframe the redesign goal from "refresh the look" to "reduce the steps a clinician needs to find and verify a product." Built a content inventory and sitemap from that foundation.

**Weeks 7–8 - User Flows & Low-Fidelity Wireframes**  
Translated IA and user stories into screen layouts in Figma. Three screens: homepage, product category page, product detail page. No color or typography - structure only.

**Week 10 - Usability Testing**  
Tested low-fidelity wireframes with real users in class. Two minor labeling issues found (filter panel clarity, search bar scope). No structural changes required.

**Weeks 11–12 - High-Fidelity Wireframes**  
Added visual design anchored to three Nielsen Norman heuristics: Aesthetic & Minimalist Design, Consistency & Standards, Recognition Over Recall. Three-color system with green reserved exclusively for CTAs.

---

## Key Design Decisions

| Decision | Rationale |
|---|---|
| Consolidated navigation labels | Existing labels used internal jargon, not clinical language |
| Search bar above the fold | Task-oriented users arrive with a product in mind |
| Price + CTA above fold on product pages | Mike persona: budget-conscious, needs no scrolling to decide |
| Three-color system (navy / light blue / green) | Replaced 6+ competing accent colors; green = action only |
| Filter panel on category pages | Dr. Sarah needs to narrow by spec in minimal clicks |
